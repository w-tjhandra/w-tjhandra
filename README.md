## Engineering Philosophy

I believe networking should not be learned only through configuration commands.

I like understanding **what actually happens underneath the configuration**:

```text
Packet
  ↓
Protocol
  ↓
Routing / Switching Decision
  ↓
Infrastructure
  ↓
Service
  ↓
Real-world Impact
```

That's why I enjoy combining:

**Theory + Lab + Troubleshooting + Real Deployment**
